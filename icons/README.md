## Usage

All icons are 24x24 viewBox, stroke-based with `currentColor` support.

```html
<!-- Direct SVG embed -->
<img src="icons/social/github.svg" width="24" height="24" />

<!-- Inline in JSX -->
<svg viewBox="0 0 24 24" fill="none">
  <path d="..." fill="currentColor"/>
</svg>
```
